# Current Architecture

## Discovery

The active discovery system is **LLM-guided lane evolution**. Strong general LLM agents inspect current Bonsai/BKG4 source, engine mechanics, compact causal failure evidence, and lane memory, then propose executable strategic program changes. Agents are hypothesis generators; exact native simulation is the authority.

The lane system preserves strategic diversity rather than ranking every candidate on one global scalar. Current lanes cover opening/finance/labour, crops/land, livestock/production, market/realization, mechanics/recovery, source-informed best responses, novel full-policy/generalist work, and router/composition.

Useful specialists may remain locally imperfect. The complete routed policy is the release-level regression unit.

## Evaluation

Every candidate passes static legality/compilation first, then a small fresh lane BUILD screen. Promising candidates receive larger CUDA confirmation across seeds, seats, multi-regime self-play and internal challengers. Frozen survivors proceed to independent INTERNAL_DEV.

Large-scale evaluation is CUDA-first. The C++ engine is the bounded reference physics oracle. New runtime behavior requires exact CPU/CUDA semantics.

Public/historical source can inform a dedicated lane only when declared `TRAINING_SOURCE`; exposed sources cannot later count as independent transfer evidence in the same epoch. Runtime policy never uses source identity.

## Routing and safety

The router/composition lane combines already-demonstrated bodies using causal legal observations. Nested binary routing and exact fallback remain the default. TRANSFER, VALIDATION, CEGIS/SEALED and the official Python canary remain downstream firewalls.

Final protected win-to-loss remains zero. `assets/champion/` is changed only through a separately reviewed promotion.

## Runtime

The submitted runtime remains deterministic Bonsai/BKG4 plus bounded declared mechanical helpers and route/program data. LLMs, neural models, search services and source-analysis tools are offline discovery infrastructure only.
