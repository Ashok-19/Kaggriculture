Verdict: **FAIL**.

This directory records the bounded implementation/falsification pass for the proposed BKG4-projected hierarchical Expert Iteration interface.

The experimental executive was implemented as an isolated legal-observation, state-conditioned economic-plan executor with deterministic task assignment, resource reservation, bounded persistent task state, and dual CPU/CUDA semantics. The frozen Shop Plus path was not modified.

The mandatory productivity gate failed decisively. On 32 fresh seeds, both seats, against a rotating frozen live panel (64 games total), the strongest bounded task-executed reference plan reached a median final cash of 12,620 versus 93,628 for paired Shop Plus. Median per-game cash ratio was 0.12993, far below the required 0.95. Utility was 0W/0T/64L.

Because the task-executed reference economy failed Gate 2 by a very large margin, the architecture stop condition was triggered. Snapshot, official-engine canary, and later full gates were not run after that mandatory stop. No neural model, Expert Iteration, PPO, league, or large search was started.

The failure is specifically a representation/executive productivity failure, not a CPU/CUDA correctness failure. Final smoke parity after the last mechanical fixes was exact across CPU and CUDA.
